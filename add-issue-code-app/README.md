# Add Issue – Power Apps Code App

React + TypeScript implementation of the "Add Issue" modal (create screen +
AI-synthesized edit screen), field order updated as requested:

1. Issue Header *(required)*
2. Original Issue *(required)*
3. Tech *(required)* | Repeat Finding
4. Criticality *(required, full-width)*
5. SOX Reportable | Accountable Function *(required)*
6. Process Area | Issue Cause Type *(required, unchanged)*
7. Primary Business Contact | Secondary Business Contact *(unchanged)*
8. **Generate & AI Synthesize** → reveals the two-pane AI Insights panel → **Save Issue**

## Integrating into a Power Apps Code App

Power Apps Code Apps are just a React/Vite (or similar) SPA that gets
registered with `pac code`. Steps:

1. **Create/init the code app** (if you haven't already):
   ```bash
   pac code init --displayName "Add Issue" -l "Custom"
   ```
   This scaffolds `power.config.json`, `.env`, and wires up the
   `@microsoft/power-apps` SDK — drop this project's `src/` contents into
   the generated project (or copy the generated config files into this
   folder) rather than the other way around, so the Power Platform tooling
   stays intact.

2. **Copy the files**:
   - Merge `index.html`, `vite.config.ts`, `tsconfig.json` into the
     `pac code init` scaffold (keep the SDK bootstrap lines it adds, e.g.
     the `initialize()` call from `@microsoft/power-apps/app`).
   - Copy `src/App.tsx`, `src/index.css`, and `src/components/*` in as-is.

3. **Wire data connections**: replace the `// TODO` markers in
   `AddIssueModal.tsx` (`handleGenerate`) and `App.tsx` (`handleSave`) with
   calls to your Power Platform connectors/Dataverse actions, e.g.:
   ```ts
   const result = await IssueAIService.Synthesize.run(form);
   await IssuesService.CreateIssue.run(data);
   ```
   These service files are auto-generated by `pac code add-data-source`
   once you connect Dataverse, SharePoint, or a custom connector.

4. **Run locally**:
   ```bash
   npm install
   npm run dev
   ```

5. **Push to Power Platform**:
   ```bash
   pac code push
   ```

## Notes

- `AddIssueModal` accepts `mode="create" | "edit"` and `initialData` so the
  same component serves both screens — pass existing record values as
  `initialData` when opening it in edit mode.
- Validation currently enforces Issue Header, Original Issue, and Tech as
  required before "Generate & AI Synthesize" or "Save Issue" will proceed,
  per your spec. Add/remove keys in `validateRequired()` if the mandatory
  set changes.
- Styling is plain CSS (no Tailwind/Fluent dependency) so it drops into any
  Code App scaffold without extra setup — swap in Fluent UI React
  components later if you want closer alignment with native Power Apps
  controls.
